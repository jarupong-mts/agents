# Internal Knowledge

Store durable internal discoveries, decisions, constraints, procedures, and
recurring failure patterns in the approved target category. Read existing pages
first; prefer update or merge to duplication. Keep complete topic metadata and
link topics from the [domain index](../index.md). ADRs use the
[ADR template](../../_template/adr.md), human evidence, and preserved history.
This example folder is not a default destination for run-specific learning.
